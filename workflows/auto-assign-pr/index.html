infoOverview

Automatically add pull request reviewers and assignees to streamline pull request triage and reviews.

folder_openWhat Gets Installed

When you run ghwm install, the following files are synchronized into your repository:

  • .github/workflows/auto-assign-pr.yaml — The workflow pipeline definition
  • ghwm.lock — Immutable lockfile tracking installed package versions
  • .github/auto_assign.yaml — Reviewer and assignee triage rules

terminalQuick Install

1. Add to ghwm.yml in your repository:

source: ghwfxlab/ghwm-registry
workflows:
  - name: auto-assign-pr
    version: 1.0.0
    update-config-files: true

2. Run CLI command:

ghwm install
